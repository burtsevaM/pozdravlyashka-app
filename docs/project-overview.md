# Project Overview

«Поздравляшка» - приложение для команд, которые хотят вовремя поздравлять коллег и не терять историю подарков.

## Problem

Поздравления часто ведутся в чатах и таблицах: сложно помнить даты, повторно не дарить одно и то же, собирать идеи и контролировать деньги.

## Goal

Сделать простой MVP-фундамент для базы участников, планирования поздравлений, коллективного выбора подарков и напоминаний.

## Users

- организатор поздравлений;
- участники команды;
- заместитель организатора на период отсутствия.

## MVP Features

- база участников;
- история подарков;
- импорт Excel;
- коллективные поздравления;
- идеи подарков и голосование;
- учет сбора средств;
- передача прав организатора;
- напоминания внутри приложения и по email.
